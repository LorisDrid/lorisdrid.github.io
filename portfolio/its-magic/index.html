It's Magic — Multi-Device Multiplayer Game

Jan 2025 ·GitHub ↗

It's Magic is an experimental multiplayer game exploring distributed interaction across several devices. Three players cooperate in a magical world using an interactive table, a vertical screen, and a mobile phone to brew a potion before time runs out.

Technologies

  • Unity 3D for table and vertical screen clients
  • Android Studio for the mobile companion app
  • WebSocket server for real-time multi-device communication
  • C# / JavaScript / Java
