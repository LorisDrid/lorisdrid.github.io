ARVARD — AR Campus Navigation

Dec 2024 ·GitHub ↗

ARVARD is an augmented reality campus navigation app built with Unity and AR Foundation. It provides an intuitive interface combining AR interaction and virtual objects to help students navigate the university campus.

Technologies

  • Unity & AR Foundation for augmented reality rendering
  • Geolocation for real-time campus positioning
  • UX Design principles for intuitive user interaction
